# TLT HOUSE — сайт вейп-магазина

Каталог с полным управлением с телефона. Есть два режима:

1. **Локально** — Node.js-сервер, данные в `data/db.json`.
2. **В интернете (бесплатно)** — GitHub Pages раздаёт сайт, а GitHub API хранит товары и фото. Правки с телефона коммитятся в репозиторий.

---

## 1. Локальный запуск

Двойной клик по `start.bat` или:

```bash
node server.js
```

- Сайт: http://localhost:3000
- Админка: http://localhost:3000/admin

При первом запуске создаётся случайный пароль админки — он выводится в консоль и пишется в `data/ADMIN_PASSWORD.txt`. Если файл пароля утерян, удалите `data/admin.json` и `data/ADMIN_PASSWORD.txt` и перезапустите сервер — сгенерируется новый.

В локальном режиме сайт отдаётся из папки `docs`, а админка работает через API сервера.

---

## 2. Публикация в интернет (бесплатно)

### Шаг 1. Репозиторий

1. Зарегистрируйтесь/войдите на GitHub.
2. Создайте **публичный** репозиторий `tlt-house`.
3. Загрузите в него всё содержимое этой папки (включая `docs/` и `data/`).

### Шаг 2. GitHub Pages

1. В репозитории: **Settings → Pages**.
2. **Build and deployment → Source:** `Deploy from a branch`.
3. **Branch:** `main`, **folder:** `/docs`. Save.
4. Через минуту сайт будет доступен по адресу:
   `https://mmatooker-rgb.github.io/tlt-house/`

### Шаг 3. Укажите свой username

Откройте `docs/config.js` и замените:

```js
owner: ''
```

на свой GitHub-логин, например:

```js
owner: 'ivanchev'
```

Закоммитьте файл. Это нужно, чтобы админка знала, в какой репозиторий сохранять изменения.

### Шаг 4. Токен для админки

1. GitHub → аватар → **Settings → Developer settings → Personal access tokens → Tokens (classic)**.
2. **Generate new token (classic)**.
3. Дайте имя, например `TLT House admin`.
4. Отметьте галочкой **repo** (для публичного репозитория достаточно `public_repo`).
5. Скопируйте токен (он показывается только один раз).

### Шаг 5. Первый вход в админку с телефона

Откройте:

```
https://mmatooker-rgb.github.io/tlt-house/admin.html
```

При первом запуске появится форма настройки:

- вставьте GitHub-токен;
- придумайте пароль админки (минимум 6 символов).

Дальше при открытии админки будет спрашиваться только пароль. Токен и пароль хранятся только в браузере вашего телефона.

## 3. Что можно менять с телефона

- добавлять / редактировать / удалять товары;
- включать и выключать наличие товара и каждого вкуса отдельно;
- менять цены, бейджи, тяги, крепость, описание;
- загружать фото устройств прямо с телефона (сохраняются в `docs/uploads/`);
- менять порядок товаров стрелками;
- редактировать тексты, ссылки на Telegram, валюту, акцентный цвет, дисклеймер;
- включать/выключать проверку 18+;
- менять пароль админки.

В GitHub-режиме изменения попадают в репозиторий коммитом и появляются на сайте за несколько секунд. Если браузер показывает старую версию — обновите страницу с очисткой кэша.

## 4. Структура

```
docs/                  сайт для GitHub Pages и локального сервера
  index.html           витрина
  admin.html           админка
  styles.css           общие стили (тёмный неон)
  admin.css            стили админки
  app.js               витрина: каталог, корзина, заказ в Telegram
  admin.js             админка: GitHub API / локальный API
  config.js            owner/repo/branch вашего GitHub
  assets/avatar.png    аватар канала
  uploads/             загруженные фото товаров
data/
  db.json              товары и настройки
  admin.json           соль и хеш локального пароля
  ADMIN_PASSWORD.txt   локальный пароль (только для локального режима)
server.js              локальный HTTP-сервер и API
start.bat              быстрый запуск на Windows
```

## 5. Ограничения бесплатного варианта

- GitHub Pages: до 100 ГБ трафика в месяц, для небольшого магазина хватает.
- GitHub API: до 5000 запросов в час с токеном — с запасом.
- Публичный репозиторий значит, что `data/db.json` виден всем. Это нормально для каталога, но не храните там секреты.
- Ссылка на `/admin.html` — только для вас. Токен даёт полный доступ к репозиторию.

## 6. Дисклеймер

Сайт рассказывает о никотинсодержащей продукции. Проверка 18+ и дисклеймер встроены. Перед публикацией проверьте требования вашей юрисдикции.
